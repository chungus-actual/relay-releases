# Greetings

Fixed list; random selection. No generated text or network calls.

- Rotation: time → weekday → unread → general; random starting category.
- One random eligible line every five minutes, checked by a one-minute timer.
- Immediate repeats excluded; older lines can repeat.
- Uses local time and the sum of reported unread counts; unknown counts count as zero.
- Hidden window: timer paused. Greeting appears on local pages in the title bar.
- `{n}` becomes the unread count.
- Source: [Greetings.cs](../Greetings.cs).
