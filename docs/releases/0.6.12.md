# Relay 0.6.12

- Stop general Facebook notifications, including Meta announcements, from inflating Messenger unread badges on Windows and macOS.
- Keep badges tied to explicit message counts and unread conversations, including encrypted chats. Clear stale counts when leaving Messages, and keep dismissed badges dismissed when unrelated Facebook notification totals change.

Existing accounts, sign-ins, encrypted-chat data, and settings are preserved. No profile reset is required.
