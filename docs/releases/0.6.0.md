# Relay 0.6.0

More friends. More noise. Fewer pixels wasted.

- YouTube Music, Spotify, and Bandcamp, with playback controls in the title bar.
- Multiple isolated accounts, custom names, and per-account audio mute.
- A slimmer title bar; zoom lives in the service’s right-click menu. Ctrl+/− and Ctrl+0 work too.
- Shared downloads, automatic crash recovery, and a quieter resource indicator.
- Fixed Messenger’s hidden-header layout, Google sign-in handoffs, and window resize corners.
- Updates download quietly from the public releases repo. **Restart to update** installs them when you’re ready.

**From 0.5.1:** quit Relay from the tray and run the 0.6.0 installer once. Settings and sign-ins stay in place. Local testing still uses Launch.cmd.

Installer and portable ZIP included. SHA-256 verification is built in; installers remain unsigned. Playback controls follow the actions exposed by each music service.
