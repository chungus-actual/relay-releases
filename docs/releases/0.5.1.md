# Relay 0.5.1

More room for messages. A little less dignity.

- Removed the bottom status bar and live-service count; services now reach the bottom of the window.
- Moved CPU and memory readings into the sidebar, including compact mode. Hover or activate them for a detailed usage card.
- Mute now visibly stays on: crossed-out bell, accent background, and a side marker. Mouse, keyboard, and accessibility toggles update the same saved setting.
- Greetings rotate every five minutes through the time of day, weekday, reported unread counts, and occasional hygiene interventions.

Quit Relay from its tray menu, then run **Relay-0.5.1-Setup-x64.exe**. Settings and sign-ins are retained. The installer is unsigned; a portable ZIP is also available.
