# Relay 0.5.0

Relay now installs as a normal Windows app with a Start-menu shortcut and a stable per-user install location. A desktop shortcut is optional. Open it from Start after installation; no batch launcher is needed.

- Setup includes .NET and installs Microsoft's WebView2 Runtime if it is missing (that step needs an internet connection).
- Reinstalling/upgrading retains settings and sign-ins. Uninstall removes app files and this installation's startup entry while retaining your profile data.
- GitHub Actions builds and checks Windows packages on pushes and pull requests. Version tags publish the installer, portable ZIP, and SHA256 checksums after installer lifecycle checks pass.
- Settings displays the compiled version automatically.

Download **Relay-0.5.0-Setup-x64.exe** for installation, or **Relay-0.5.0-win-x64.zip** for a portable copy. The build is unsigned. Quit any running Relay through its tray menu before installing. If you previously enabled startup for a portable copy, enable it once from the installed copy's Settings to use the stable path.

The release retains the compact UI, seven services, isolated browser profiles, resource footer, bounded logging, and focus-retention fix from 0.4.2. See the memory-soak report for the synthetic lifecycle validation and its limits.
