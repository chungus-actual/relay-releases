Inspect `gh release view windows-candidate-0.6.12 --repo chungus-actual/relay --json targetCommitish,body,assets,isDraft`. Require the draft's pinned `targetCommitish` to equal `git rev-parse HEAD`. 2. Run `bash scripts/Test-macOS.sh`, `bash scripts/Test-macOS-browser.sh --unread`, and the full WebKit browser suite with `bash scripts/Test-macOS-browser.sh`. Run `python3 scripts/Test-release.py`.
