# Relay 0.6.9

- Find accounts, saved places, and common actions with the command palette: **Ctrl+K** on Windows or **Command+K** on macOS. Its launcher can be hidden without losing the keyboard shortcut.
- Save named workspaces and account-specific bookmarks. Search, open, edit, and organize them without replacing your existing browser sessions or drafts.
- Search Settings, choose account identity colors, and snooze notifications globally or per account.
- Export and import a portable Relay setup across platforms. Setups include preferences and saved places; sign-ins and browser profiles stay on their original device.
- Keep a searchable download history across restarts. Clearing history keeps downloaded files.
- Save a bug report with reviewed diagnostics and an optional screenshot. Online submission is not enabled in this build.
- Enable inline predictive text for macOS WebKit pages and popups from Settings. Changes apply after restarting Relay and follow the macOS Keyboard setting.
- Improve companion outfits across standing, seated, and sleeping poses, and add Groom for Puke, Shake for Roof, and Polish for Rock.
- Improve Messenger display refresh for large conversations and add a manual refresh action that preserves the current document, scroll position, and draft.
- Fix macOS sheet controls using the wrong light/dark appearance and preserve stable identities when restoring download history.

Existing accounts, sign-ins, and settings are preserved. Notification snoozes remain subject to system notification permissions and Focus/Do Not Disturb settings.
