# Relay 0.6.4

- Add Discord accounts on Windows and macOS, with separate sign-ins and Relay's existing notification and title-based unread controls.
- The macOS **Add account** button responds across its full width, shows hover and pressed feedback, and opens a service-selection dialog.
- Discord's logo renders correctly on macOS, with the same vector artwork shared by Windows.

Downloads:

- [Windows installer](https://github.com/chungus-actual/relay-releases/releases/download/v0.6.4/Relay-0.6.4-Setup-x64.exe)
- [Windows portable ZIP](https://github.com/chungus-actual/relay-releases/releases/download/v0.6.4/Relay-0.6.4-win-x64.zip)
- [macOS universal ZIP](https://github.com/chungus-actual/relay-releases/releases/download/v0.6.4/Relay-20.zip) — macOS 14+, internal build 20

Existing accounts and profiles are preserved. On existing macOS installations, use **Settings → Add account → Discord**. Windows updates through **Restart to update**; macOS updates through **Check for Updates**.

The Mac package is Developer ID signed and notarized for Apple silicon and Intel. Discord calls, screen sharing, and push delivery remain unverified; server/channel unread scanning is not implemented. Normal macOS builds use WebKit; Windows uses WebView2.
