# Relay 0.6.5

- Keep Google's YouTube session handoffs inside the originating account on Windows and macOS, including authentication popups.
- Keep Messenger CDN attachments in Relay's Windows download drawer when link capture is off, matching macOS.
- Finish Windows popup downloads even when the browser automatically closes the attachment window; release the hidden popup after completion or cancellation.
- Check shared Messenger, Gmail and media scripts for parity in both platform CI workflows.

Existing accounts and profiles are preserved. Normal macOS builds use WebKit; Windows uses WebView2. macOS internal build: 21.
