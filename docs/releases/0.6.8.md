# Relay 0.6.8

- Remove Messenger's extra outer scrollbar while keeping the chat list and conversation independently scrollable. The composer stays within the window when resizing, zooming, or switching chats.
- Match WhatsApp's native scrollbars to its light or dark theme, including when it differs from Relay's appearance.

Both fixes were confirmed on live macOS pages. Existing accounts, sign-ins, and settings are preserved.
