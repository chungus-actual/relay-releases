First macOS preview of Relay, with the native macOS shell and optional Chromium engine.

- Universal app for Apple silicon and Intel; requires macOS 14 or later.
- Separate service profiles, downloads, notifications, media controls, and appearance settings.
- Signed Sparkle updates through the public Relay releases repository.

This preview uses a local self-signed certificate and is not notarized by Apple. macOS may require approval in Privacy & Security when opening a downloaded copy. Chromium DRM/proprietary media support and provider-specific calling/screen sharing remain under evaluation.

Download `Relay-2.zip`, extract it, and move Relay.app to your Applications folder. Keep your existing Relay profiles; this build does not migrate or remove them.
