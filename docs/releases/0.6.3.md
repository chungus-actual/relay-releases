# Relay 0.6.3

Windows and macOS now share one version and release page.

- Gmail badges support **New since launch** and **All unread**, with consistent inbox detection and activity clearing across both platforms.
- Messenger refreshes retained chat content when switching back, preserving drafts and scroll position.
- macOS includes the confirmed file-drop routing fix, faster service switching, consistent Safari browser identification, and the restored title-bar Relay logo.
- The macOS app is Developer ID signed, Apple-notarized, and universal for Apple silicon and Intel. Normal builds use WebKit; Windows uses WebView2.

- [Windows portable ZIP](https://github.com/chungus-actual/relay-releases/releases/download/v0.6.3/Relay-0.6.3-win-x64.zip)
- [macOS universal ZIP](https://github.com/chungus-actual/relay-releases/releases/download/v0.6.3/Relay-16.zip) — macOS 14+, internal build 16

Existing accounts and profiles are preserved. Windows updates through **Restart to update**; macOS updates through **Check for Updates**. Historical downloads remain available. macOS menu-bar icon visibility remains under investigation.
