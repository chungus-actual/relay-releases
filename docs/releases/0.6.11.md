# Relay 0.6.11

- Fix encrypted Messenger conversations failing to load on Windows when Terminal is enabled. Terminal's request filter now stays within its own page instead of blocking other services' background workers.
- Add Previous, Play/Pause, and Next controls to the Windows taskbar hover preview. Controls follow the playing service, remain available while you use another service, and hide when playback is no longer available.
- Keep Terminal's network and worker restrictions isolated from other services on both platforms.

Existing accounts, sign-ins, encrypted-chat data, and settings are preserved. No profile reset is required.
