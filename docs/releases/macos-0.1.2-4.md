Gmail unread detection now tracks the inbox badge even while another folder or message is open.

- Choose **New since launch** or **All unread** per Gmail account. New since launch is the default and ignores the existing backlog, counting net unread increases.
- Switching modes clears old badge/activity state without sending an alert.
- About now reads: “Thin apps. Thicc brain.”

Includes the scrolling media titles from 0.1.1. Requires macOS 14 or later on Apple silicon or Intel.

This preview is self-signed and not notarized. WebKit may request WebCrypto Keychain access once for each new build; existing keys and service profiles are preserved.
